# Project Scope

## Project Purpose
To build a personal coding portfolio using HTML, while developing foundational web development skills. This project applies structured planning to support future coursework and strengthen my resume.

## Description
This project develops HTML skills and helps me understand how it is built. With a single webpage, I will build the structure and HTML elements for the project.

## Desired Results
- A completed index.html file that serves as a functional portfolio landing page
- A well-organized scope.md document that clearly defines project parameters and objectives
- Demonstration of HTML elements and structures
- Clear articulation of professional goals and interests
- To give a clear coding lines for my project

## Exclusions
- No CSS unless it is used in HTML
- No database integration or backend functionality
- No multi-page structures; single-page portfolio only
- No JavaScript or other programming languages
- No social media integration or analytics tracking
